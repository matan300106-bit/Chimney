# בית כורכר – וילת בוטיק בקיסריה

פרויקט גמר – הנדסאים, אדריכלות ועיצוב פנים · מנחה: **שירן שריקי**

וילת בוטיק במגרש לימודי בשכונה 13 (שכונת הגולף) בקיסריה. מגרש 30×36 מ' (1,080 מ"ר), רחוב ממזרח ומגרש הגולף ממערב.
הקונספט: **"רכס ואופק"**. קומת קרקע כבדה בחיפוי אבן בגוון כורכר היא ה"רכס", ומעליה מונח בניצב נפח לבן וקל, "האופק",
שנשלח 5 מ' בזיז מעל הגן והבריכה וממסגר את האופק בלוג'יה של סוויטת ההורים.

## איך זה בנוי (`src/`)

כל הגיליונות, קובצי ה-DXF וההדמיות נוצרים ממודל פרמטרי אחד (`model.py`), ולכן תכנית, חזית, חתך והדמיה תמיד תואמים זה לזה.

* `model.py` – מקור האמת: קירות, פתחים, תקרות, מדרגות, חדרים, ריהוט ופיתוח.
* `geom.py` – המרת המודל לתיבות תלת-ממדיות.
* `plans.py`, `elev.py` – תכניות, חזיתות וחתכים. החזיתות והחתכים הם הטלה של המודל, עם צללים ב-45°.
* `siteplan.py`, `structure.py`, `schedule.py`, `details.py`, `interior.py`, `joinery.py`, `concept.py`, `cover.py`, `renders.py` – גיליונות ייעודיים.
* `qa_check.py` – בודק אוטומטי למידות, תקנות (מדרגות 2R+T, מעקות, ממ"ד, גובה תקרה), שטחים וזכויות.
* `render_blender.py` – הדמיות Cycles.

```bash
cd src
python3 build.py              # כל הגיליונות + PDF מאוחד
python3 build.py 6 11 --png   # גיליונות נבחרים + PNG
python3 qa_check.py           # בדיקת מידות ותקנות
```

תלויות: Python 3.11, shapely, ezdxf, pypdf, bpy 4.2 (להדמיות), Node + Playwright (Chromium) להפקת PDF.
